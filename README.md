# TheoDoros_St_ — Personal Portfolio

A small, responsive personal portfolio website in Greek, published with GitHub Pages.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

This is the user site repository for `theostog`. GitHub Pages serves it at:

https://theostog.github.io

Configure it in **Settings → Pages** to deploy from the `main` branch and the root folder if GitHub Pages is not already enabled.
